# Cpp-coding

本人从零学习C++的全部代码，包含基础语法以及一些算法。

## 项目结构

```
Cpp-coding/
├── exercises/                # 练习代码（洛谷）
│   ├── practice-2026/       # 2026年日常练习（28个文件）
│   ├── practice-20262/      # 2026算法练习（53个文件）
│   ├── practice-20263/      # 2026算法专项练习（57个文件）
│   └── practice-standalone/ # 零散练习代码（6个文件）
│
├── experiments/              # 课程实验
│   ├── lab01/ ~ lab09/      # 实验01-09
│
├── exams/                    # 考试代码
│   ├── exam-papers/         # 考试题目解答
│   └── programming-exam/    # 编程考试练习
│
├── projects/                 # Visual Studio 项目
│
├── docs/                     # 文档
│
├── .gitignore               # Git忽略文件
│
└── README.md
```
